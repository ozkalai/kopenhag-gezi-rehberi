# København — Melih & Parıltı

21–24 Kasım 2026 için mobil uyumlu Kopenhag gezi rehberi.

Site statik tek dosyadır (`index.html`); JavaScript olmasa da gezi rotaları ve restoran önerileri görünür.

## GitHub Pages yayını
1. Bu depoda **Settings → Pages** bölümünü aç.
2. **Build and deployment / Source** olarak **Deploy from a branch** seç.
3. **Branch:** `main`, **Folder:** `/ (root)` seç, **Save** butonuna bas.
4. GitHub Pages yayını tamamlanınca site adresi: https://ozkalai.github.io/kopenhag-gezi-rehberi/

Harita ve bilet bağlantıları için internet gerekir. Etkinlik saatlerini ziyaret öncesinde doğrulayın.
